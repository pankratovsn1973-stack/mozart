📚 ДОКУМЕНТАЦИЯ ПРОЕКТА MOZART ERP
🏗️ ОСНОВНАЯ АРХИТЕКТУРА

Проект представляет собой Low-code конфигуратор для ERP-системы Mozart. Визуальный дизайнер форм, редактор справочников, конструктор импорта данных.
Технологический стек:

    GUI: PySide6 (Qt for Python)

    База данных: PostgreSQL

    Графика: QGraphicsScene/QGraphicsView

    Движок импорта: Собственный, с поддержкой JSON/XML/DBF/CSV/Excel

🎯 КЛЮЧЕВЫЕ ПОНЯТИЯ
1. Сущность (Entity)

Базовый объект системы. Бывает двух классов:

    DICT — справочник (иерархический, версионный)

    DOC — документ (зависимый, версионный)

2. Поле (Field)

Атрибут сущности. Может быть:

    Простым (C, I, N, D, T, L, M)

    Ссылочным (R) — ссылается на другую сущность

3. Экземпляр (Instance)

Конкретная запись сущности. Имеет версии (Version).
4. Композиция (Composition)

Связь "родитель-потомок" между сущностями. Используется для построения иерархий.
5. Форма (Form)

Визуальное представление для работы с сущностью. Состоит из контролов.
6. Контрол (Control)

Элемент формы: текстовое поле, ссылка, таблица и т.д.
7. Балансовая единица (Balance Unit)

Единица учёта (организация, подразделение). Определяет видимость данных.
